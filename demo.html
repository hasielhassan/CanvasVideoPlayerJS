How this works:

This page imports and uses a CanvasVideoPlayer class from canvas-video-player.js. The class handles all logic for drawing to the canvas, syncing audio, and managing the custom controls.

Security & Obfuscation Features:

  • Custom Controls: By replacing the browser's default video/audio controls, we remove the "Download" and "Picture-in-Picture" buttons, giving us full control over the user's interaction.
  • Blob URL Loading: The load() method fetches the video file in JavaScript and loads it into the player as a blob: URL. This prevents anyone from simply right-clicking, "Inspect Element," and finding the direct .mp4 URL in the HTML.
  • Disclaimer: This method deters casual users. A tech-savvy user can still open the browser's "Network" tab to see the original file being downloaded. True protection requires server-side solutions like expiring URLs or encrypted streaming (HLS/DASH).
